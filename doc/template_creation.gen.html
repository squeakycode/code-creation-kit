Template Creation

Before starting to create a template the tables of the data model need to be created because for writing macros it is mandatory to know how the data can be accessed. After this is done it is a good practice to write a reduced version of the code that is to be generated from the data tables. Considering the parameter list example from the getting started section this could be a data class with one member. Now that it is clearer how the output should look like replace the sections to be generated with the corresponding macro expressions one by one.

After creating a command file it is possible to check that the output is as expected for each step. To do this, create a new text file with the extension tccmd and add the required commands. Further information on commands can be found in the getting started section and the command reference. When double clicking on the command file a shell window opens, the command file is processed and the result is displayed. The processing can be rerun by pressing the ‘r’ key after each modification of the template file. Opening the generated file in an editor, e.g. PSPad, that detects changes to the opened documents provides a convenient way to view the produced result.
