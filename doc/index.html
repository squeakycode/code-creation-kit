Introduction

A software project often contains some dull and repetitive tasks. Let’s take program options of any kind for an example, e.g. a command line interface. For every program option you need to write a boiler plate code fragment. Additionally every single program option has to be documented somewhere else. Now that’s somewhat boring. You can easily gather all options in a spreadsheet including any documentation. Wouldn’t it be good to simply generate code and user documentation from the spreadsheet table data? Here is where the code-creation-kit comes in. The code-creation-kit mainly consists of a text compiler that can be used to generate code for any text based programming language for any coding problem that involves a lot of repetition. The input of the text compiler is modeled in table and template files. Powerful multistage macro expressions in the template files control how the data from the data tables is converted into code. The getting started section shows in more detail how this works.

Benefits

  • Productivity is increased when generating code.
  • Less Testing is required.
  • Multistage macro expressions allow accomplishing complex generation tasks.
  • Code can be generated in-place using inline templates.
  • Once the table layout is defined and a template is written for a common coding problem the implementation effort is cut down to a minimum for the future.
  • All the powerful and convenient features of a spreadsheet application can be used to create data tables.
  • The kit can be used to create code for any text based language.
  • The text compiler can be integrated into many development environments.
  • The text based table format allows the tracking of changes in a version control system.
  • The text compiler is very stable due to high unit test coverage.
