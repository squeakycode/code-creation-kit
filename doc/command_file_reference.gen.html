Command File Reference

The following table shows all available commands.

Option Group Option Name Short Description
Load Table
load-table Name of the table file to load. Default when the option name is omitted.
label a Specifies the label used for identifying the table when unloading. The label defaults to the name of the table passed.
top-down t Indicates that the table is to be read top down. If no direction is explicitly specified all directions will be read by default.
left-to-right l Indicates that the table is to be read from left to right. If no direction is explicitly specified all directions will be read by default.
row-header-index w Specifies the one based index of the column containing the row names. If zero is passed the one based index of the row is used as row name.
column-header-index n Specifies the one based index of the row containing the column names. If zero is passed the one based index of the column is used as column name.
pad-rows Automatically fills missing row items at the end of a row with an empty string.
Unload Table
unload-table x Unload table file identified by its label. This option accepts multiple parameters for unloading more than one table. Tables having the same label are unloaded in the reverse order they are loaded.
Generate File
template-source-file s Specifies the file containing the template.
output-file o Specifies the file to output to.
parameter p Optional parameters used by the template forming an additional table. This option accepts multiple parameters. Therefore it must be provided last.
use-intermediate-output-file u Indicates that the output shall be written to an intermediate file first. This file replaces the primary output file when the generation succeeded and the intermediate and the primary output files are different otherwise it is being removed.
intermediate-file-extension e The name of the intermediate file is produced by adding the given extension to the name of the output file. The extension defaults to '.intermediate' when omitted.
markup-prefix Sets the initial tag markup prefix.
markup-postfix Sets the initial tag markup postfix.
markup m Sets the initial tag markup prefix and postfix. This switch overrides the switches markup-prefix and markup-postfix.
append-to-file The output is appended to the target file. This option is ignored when used together with the use-intermediate-output-file option.
inlined Indicates that a file with inline templates is processed. An intermediate file is automatically used when processing files with inline templates if no output file is provided. Use this option carefully to prevent data loss. Consider using the recycle option.
inline-prefix b A prefix that marks a line of an inline template file as template content. This string must not be empty.
inline-postfix c A postfix that marks a line of an inline template file as template content. This string can be empty.
inline-generated-postfix d A postfix that marks a line of an inline template file as generated content. This string must not be empty.
inline-pad The number of characters a generated line is padded up to with spaces before the generated postfix is appended.
recycle y Used together with inlined option. If possible the target file is moved to the recycle bin of the system before it is replaced by the intermediate file.
can-change-table-list Allows a template to change the table list provided to the generator, e.g. by adding or removing tables. The default setting is off. A template can always use temporary tables during processing.
Reset Generator
reset r Reset the generator to defaults.
Add Include Directories
add-include-directory i Adds an include directory. This option accepts multiple parameters.
CSV Table Properties
csv-delimiter-chars Specifies a list of delimiter characters for the next CSV-files to load. Use "\t" for tab separated items. Use an empty string for no delimiter.
csv-comment-chars Specifies a list of characters as string that mark commented lines in CSV-files when found at the beginning of a line. The default is no commenting characters used.
csv-quote-chars Specifies a list of characters as string that are used for quoting text items in CSV-files. The default is the double quote character.
Logging
log-file Sets up logging as follows: 'none' is off, '-' is log to stdout, and any other parameter value is the name of a log file.
