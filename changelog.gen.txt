Development Snapshot
==========================================================================

This is a development snapshot.

Change      Tracker ID Description
----------- ---------- ---------------------------------------------------
New Feature            Excel CSV-saver add-in has been extended by the
                       method SaveActiveWorkbookToCsvFilesUtf8 that
                       allows to save tables with UTF-8 encoding.

Bugfix                 Excel CSV-saver add-in now saves the line endings
                       correctly when cells contain line breaks.

Improvement            The CSV parser now skips over byte order marks
                       (BOM). BOMs have otherwise the effect that first
                       column or row is not found when generating. This
                       condition is hard to identify, because BOMs are
                       usually not visible.

Bugfix                 Fixed an issue where a CSV-file failed to load
                       when then last cell was empty and not terminated
                       by a new line character.

New Feature            Added TO_SIZE conversion tag. This tag can be used
                       for determinating the size of text entries.

New Feature            Added TO_CSV conversion tag. This can be used for
                       putting text items in quotes correctly when
                       creating CSV tables.

Bugfix                 Fixed an issue that could cause to paths to not be
                       determined correctly on Unix based operating
                       systems. Furthermore absolute paths are now
                       normalized instead of using the provided path
                       directly.

New Feature            Added process-instant-template command line option
                       for processing an instant template file (extension
                       itpl). An instant template file contains or loads
                       all needed tables. The name of the output file is
                       build by removing the extension. This option can
                       be specified multiple times. The commands are
                       executed in the order they are specified.

Improvement            Renamed command file parameter csv-delimiter to
                       csv-delimiter-chars. Multiple delimiters can be
                       supplied.

Improvement            Replaced  command file parameter csv-ignore-quotes
                       with csv-quote-chars. You can pass an empty string
                       to ignore quotes.

New Feature            Added CALC conversion tag for computing arithmetic
                       expressions.

Bugfix                 Fixed an issue where multiple of either PAD_LEFT,
                       PAD_RIGHT or BLOCK_FORMAT tags failed to work as
                       expected.

This release adds in-place generation using inline templates, logging for
debugging support, and more CSV-file handling features.

Please note that this is a new tool and it is still missing some features.
