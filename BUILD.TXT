How to build under Microsoft Windows
====================================

Required Tools and Libraries
----------------------------


Tool                    Used Version     Where to get                Needed for
----------------------  ------------ ------------------------------- ------------
Microsoft Visual Studio         14.2 www.microsoft.com               build

CMake                            3.8 cmake.org                       build

boost C++ library               1.70 www.boost.org                   build

Makefile, Project and          1907  www.ociweb.com/products/mpc     examples
Workspace Creator - MPC              github.com/DOCGroup/MPC

Perl, e.g. ActivePerl                www.activestate.com/activeperl  examples

highlight                       3.23 www.andre-simon.de              documentation

Inno Setup Compiler     5      5.5.6 www.jrsoftware.org              windows setup

Inno Setup Preprocessor              ispp.sourceforge.net            windows setup


The boost C++ library needs to be build. Consult the boost documentation on how
to do it.

The environment variable BOOST_ROOT needs to be set, e.g. BOOST_ROOT=C:\libs\boost_1_70_0

The environment variable MPC_ROOT needs to be set, e.g. MPC_ROOT=C:\MPC

Creating the Projects and Solution:

The create_workspace.cmd batch in the tools folder can be used to create
the project and solution files for building using cmake.

There are two ways the solution can be created. If a text compiler is already
available (CCK_ROOT is set) then the projects use the text compiler to
generate code otherwise pregenerated code is used to build the first text
compiler.

The build text compiler can be found in the output folder.

Creating the Documentation:

The documentation can be created using the _rebuild_documentation.cmd from
the docsource folder. The result can be found in the output folder.

The subfolders themes and langDefs of %ProgramFiles%\WinHighlight
(see highlight above) need to writable under Vista and Windows 7, because
the syntax definitions of the text compiler need to be placed there.
This is a problem with activated User Account Control (UAC).
A possible solution for this is to change the access rights to these folders.

Creating the setup:

The setup can be created using the make_release.cmd from the tools folder.

Please make sure that any version numbers you create do not clash with
the ones from official code-creation-kit releases.


How to build under Linux
=============================

Tool                    Used Version     Where to get                Needed for
----------------------  ------------ ------------------------------- ------------
boost C++ library               1.58 official package repository     build

CMake                            3.8 official package repository     build

Get the boost development package. Run cmake. Run make. The result of build can be
found in the output/bin folder.
