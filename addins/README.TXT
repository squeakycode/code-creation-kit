Installing the CSV-Saver Template for Microsoft Office Word
-----------------------------------------------------------
Copy Code-Creation-Kit_CSV-Saver.dot to %appdata%\Microsoft\Templates\
Open Word
Select File->Options
Select Addins
Select Templates in "Manage" Drop-Down Box
Select "Go..."
Add Code-Creation-Kit_CSV-Saver.dot
Select "Quick Access Toolbar" 
Select "Popular Commands"
Select "Macros"
Add CodeCreationKitCsvSaver
Press the button in the Quick Access Toolbar to save a document
from folder docsource to the corresponding CSV-File.
